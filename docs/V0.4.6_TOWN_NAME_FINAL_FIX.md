# v0.4.6 Town-name final fix

Root cause confirmed against the real GAFE01 USA disc and the converted PAL Spanish pack.

- `mMsg_CopyCountryName()` still executed a Japanese leftover suffix path.
- That path loads string id `0x1E4` (484).
- GAFE01 string 484 is `common butterfly`; Spanish PAL converts it to `mariposa comun`.
- TARGET_PC (Windows and Android port) now inserts the saved town name verbatim and never executes that suffix path.
- The earlier `mLd_AddMuraString()` protection remains in place for other town-name call sites.
- Language packs do not need to delete or alter the butterfly item name.
- No City Folk / CityExpansion changes.
