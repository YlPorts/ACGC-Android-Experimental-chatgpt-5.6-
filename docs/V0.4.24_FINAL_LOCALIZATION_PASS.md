# v0.4.24 FINAL LOCALIZATION PASS

Includes everything through v0.4.23 plus 19 calendar/clock text textures:
- 12 localized month-name I4 textures (64x16, 0x200 each)
- 7 localized weekday I4 textures (64x16, 0x200 each)

Languages: ES/FR/DE/IT.

This closes the last large, verified block of ordinary visible text that was
still baked into textures instead of language strings.

Remaining intentionally untranslated/unreplaced categories:
- Debug/developer-only screens.
- Memory Card filenames/internal save identifiers.
- Artwork whose text/content could not be verified safely.
- Copyright/legal artwork where altering the original legal notice is not appropriate.
- A few registered notice-board/end-screen graphical slots without verified replacement artwork.

The project should now be considered localization-complete for normal gameplay
text/UI, with the above categories excluded by design.

No City Folk / CityExpansion content.
