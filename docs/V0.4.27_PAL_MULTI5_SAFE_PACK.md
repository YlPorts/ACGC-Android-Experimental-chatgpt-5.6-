# v0.4.27 - PAL Multi5 safe language pack

This revision keeps the original V4 runtime and launcher identity intact.

The previous experimental whole-file PAL `audiorom.img` override was removed.
Those PAL audio ROM images are not treated as drop-in replacements for the USA
runtime because their layouts/sizes differ by regional executable and caused a
runtime close on Android.

The external language packs remain ROM-safe for text, item/name tables, grammar,
UI strings and verified graphical resources. Missing/unsupported resources fall
back to the USA disc data.

Regional audio must be ported at a finer-grained level before it can be enabled
again safely. Until then the game keeps the USA audio ROM.
