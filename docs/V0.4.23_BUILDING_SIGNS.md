# v0.4.23 cumulative building-sign localization

Includes everything in v0.4.22 plus generated localized CI4 signs based on
verified USA source textures extracted from the user's legal USA image.

Verified originals:
- tailor_sign.bin: 32x16 CI4, original artwork reads ABLE SISTERS.
- shop4_sign.bin: 64x32 CI4, original artwork reads THANK YOU!.

Generated labels:
- ES: MANITAS / GRACIAS
- FR: SOEURS / MERCI
- DE: SCHNEID / DANKE
- IT: SORELLE / GRAZIE

Safety:
- Tailor sign preserves the original shared building palette and replaces only
  CI4 indices, avoiding recoloring the building.
- Shop sign keeps the original USA palette and provides it unchanged because
  v0.4.19 applies that texture/palette pair atomically.
- Missing replacements still fall back to USA artwork.

These are port-generated localizations, not claimed to be official PAL artwork.
No City Folk / CityExpansion content.
