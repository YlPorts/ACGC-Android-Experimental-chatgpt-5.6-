# v0.4.10 True Cumulative MultiLanguage

This release is generated against a reconstructed clean v0.4.6 base that does
not contain the ui_strings.ini loader.

It therefore includes, in one patch:
- pc_language_ui_lookup()
- pc_language_ui_copy()
- complete ui_strings.ini parser/loader and storage
- load hook from pc_language_init()
- runtime location-name lookup
- fixed edit-screen UI strings
- warning/system-text localization
- cumulative ES/FR/DE/IT ui_strings.ini files
- v0.4.6 town-name final fix remains preserved
- no City Folk / CityExpansion content

The standalone language packs still contain the PAL ARAM/item/NPC resources.
The source-tree ui_strings.ini files are included so the cumulative patch is
self-contained for the fixed UI text layer.
