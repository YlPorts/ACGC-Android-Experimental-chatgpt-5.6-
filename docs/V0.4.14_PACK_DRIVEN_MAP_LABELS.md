# v0.4.14 cumulative pack-driven map labels

Includes everything in v0.4.13 plus:
- Removes compiled ES/FR/DE/IT building-label arrays from m_map_ovl.c.
- Map labels now resolve through ui_strings.ini.
- Supports two-line pack keys for police station, post office, wishing well and train station.
- Shop, dump, museum, tailor and dock use their existing location.* pack keys directly.
- English remains the original built-in fallback.
- No City Folk / CityExpansion content.

Remaining localization audit:
- Most normal dialogue/letters/items/NPC names are already supplied by PAL packs.
- Main menu, pause, settings, catalog, warnings, editor prompts, inventory actions,
  diary prompt and map labels are pack-owned.
- Remaining literal-looking strings are predominantly developer/debug labels,
  comments describing message IDs, save-format metadata, or graphical assets.
- Graphical/textured labels still need a separate resource pass.
