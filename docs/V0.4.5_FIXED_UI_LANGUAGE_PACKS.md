# v0.4.5 Fixed UI language packs

This pass extends the external language-pack format with `ui_strings.ini`.

Translated through the pack:
- Text editor headings such as Enter Destination, Enter your name, catchphrase, song request and design/island naming.
- Address book prompts.
- Confirmation prompts.
- Secret-code prompt.
- Loan and clock labels.
- Gyroid shop/house-sale helper messages.

Existing PAL dialogue, mail, item-name, NPC-name and grammar resources are unchanged.
Missing `ui_strings.ini` or missing keys safely fall back to the original English strings, so old packs remain compatible.
No City Folk / CityExpansion changes are included.
