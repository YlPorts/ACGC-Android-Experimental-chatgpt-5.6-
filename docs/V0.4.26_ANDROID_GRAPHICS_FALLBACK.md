# v0.4.26 Android graphical localization reliability fix

The v0.4.25 packs contained the translated graphics, but user testing still
showed the USA originals. v0.4.26 keeps external pack graphics as first choice
and adds compiled ES/FR/DE/IT fallback copies for the screenshot-verified labels.

Embedded fallback coverage:
- HUD weekdays + AM/PM
- Camera / Lights
- diary Entry / latest entry / Write / Quit
- Items / Letters / Bells
- Insects / Fish
- melody e-Reader / Play / Erase all

This guarantees these generated labels can localize even if Android's external
pack installation omitted or misplaced the graphics directory.

Performance:
- Retains v0.4.25 binary-search ui_strings lookup.
- External graphic load now validates and reads in one fopen instead of two.
