# v0.4.27 PAL Multi5 audio/language pack support

This revision keeps the USA disc image as the base and extends external language packs.

Supported external pack layout:
- `languages/<code>/aram/` translated ARAM text resources
- `languages/<code>/items/` item-name/grammar data
- `languages/<code>/graphics/` exact-size localized UI textures
- `languages/<code>/ui_strings.ini` fixed UI labels
- `languages/<code>/audio/audiorom.img` optional regional audio image

The runtime only checks `audiorom.img` for the regional audio override. If it is missing or invalid,
the original USA disc audio is used. Models, game logic, saves and arbitrary DVD files are not
replaceable through a language pack.

The PAL-derived language packs themselves are intentionally not stored in this source repository.
