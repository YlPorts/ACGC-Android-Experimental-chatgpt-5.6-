# v0.4.19 cumulative safe graphical-language switching

Includes everything in v0.4.18 plus:
- Graphical override slots snapshot their USA/original bytes lazily after pc_assets_init.
- Every pc_language_init() restores original artwork before applying another language.
- pc_language_shutdown() also restores original artwork.
- Paired graphical resources can be registered atomically.
- Nook shop sign CI4 pixels + TLUT now load only when both exact-size files are present.
- Wrong-size or incomplete graphic pairs fall back to the USA artwork.
- Graphics registry remains 128 slots.
- No guessed/redrawn translated Nintendo graphics are bundled.
- No City Folk / CityExpansion content.
