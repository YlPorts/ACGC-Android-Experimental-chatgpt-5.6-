# v0.4.15 graphical-text infrastructure

- Raises ui_strings.ini capacity from 128 to 512 entries. v0.4.14 packs already exceeded the old runtime limit, so keys after entry 128 could silently fall back to English.
- Adds exact-size graphical-text overrides under languages/<code>/graphics/.
- Registers editor text-bearing textures (letters, OK, backspace, space, caps, small) as optional graphical overrides.
- Missing graphical overrides always keep the original USA texture.
- Rejects wrong-sized override files instead of copying them.
- This release adds the infrastructure and manifest; translated texture binaries still require authored graphical replacements.
- No City Folk / CityExpansion content.
